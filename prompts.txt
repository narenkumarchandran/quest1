- "for users who dont have the gpu but the input video file requires whisper model to run in that case they can use googel colab like that cloud provider" -> "add this in the approach and readme"
  Challenge: Heavy compute requirements (`faster-whisper`, `EasyOCR`) alienate users without local GPUs.
  Resolution: Updated `README.md` and `approach.md` to formally recommend running the pipeline on cloud providers (like Google Colab or Kaggle) utilizing free GPU tiers.
- "Explain the error(on Dailymotion ConnectionResetError 10054)"
  Challenge: Dailymotion's aggressive anti-bot firewall (Cloudflare) was blocking `yt-dlp` requests from automated IPs.
  Resolution: Identified the block and instructed the installation of `curl_cffi` to enable browser TLS impersonation.
  Challenge: `yt-dlp` required explicit flags to activate impersonation, which wasn't exposed in the `main.py` CLI.
  Resolution: Modified `src/pipeline/downloader.py` to hardcode `--impersonate chrome` directly into `_YTDLP_BASE`.
- "https://vimeo.com/92760926... The web client only works when logged-in" -> "add it" (Adding cookies support)
  Challenge: Age-restricted or private videos on Vimeo were blocking anonymous downloads, and Windows DPAPI blocked reading cookies from Chromium browsers.
  Resolution: Added `--cookies-from-browser firefox` to `_YTDLP_BASE` to bypass authentication walls using the local Firefox session without triggering DPAPI encryption errors.
